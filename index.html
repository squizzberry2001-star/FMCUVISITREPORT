Sinkronisasi otomatis 2 arah untuk Master User & Password (users), Master Toko (stores), Master Jadwal (schedules), dan Laporan (reports).

Perhatian: Firestore Security Rules Masih Terkunci (Permission Denied)

Agar aplikasi web dapat menyimpan & membaca Master User, Password, Master Toko, dan Jadwal Visit secara otomatis di project fmcu-visit-database, silakan buka Firebase Console → Firestore Database → Tab Rules, tempel aturan berikut, lalu klik Publish: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

Kode Google Apps Script Siap Pakai (`Code.gs`)

Salin skrip ini ke Google Apps Script Anda untuk mengaktifkan auto-upload PDF ke Google Drive & auto-email

Panduan Singkat Aktivasi Auto-Upload Google Drive & Email:
  1. Buka script.google.com dan buat project baru.
  2. Tempel kode dari tombol Salin Kode (atau file google-apps-script/Code.gs).
  3. Klik Deploy → New Deployment → Web App (Execute as: Me, Access: Anyone).
  4. Tempel URL Web App ke kolom di samping dan klik Simpan.
