Batas Kuota Cloud Firestore (Error 429)

Panduan solusi sinkronisasi jadwal & lokasi antar perangkat

Mengapa Jadwal di Perangkat Lain Tidak Update?

Firebase Spark (Paket Gratis) memiliki batas maksimal harian 50.000 baca & 20.000 tulis per hari. Saat kuota habis, Firestore menolak request dengan status 429 RESOURCE_EXHAUSTED hingga kuota direset oleh Google pada pukul 15:00 WIB setiap hari.

Pilihan Solusi yang Tersedia:
1 Solusi Permanen (1 Menit): Upgrade ke Blaze di Firebase Direkomendasikan

Buka Firebase Console → Project fmcu-visit-database → Upgrade Plan ke Blaze (Pay as you go).
Catatan: Kuota gratis 50.000 baca/hari tetap berlaku Rp 0, namun blokir 429 langsung hilang seketika dalam 1 menit!

2 Solusi Instan: Bagikan File Jadwal (.json / WhatsApp) Langsung Jalan

Admin cukup klik tombol "Bagikan Jadwal" untuk mengunduh file atau menyalin ke WA. User di perangkat lain cukup klik "Impor Jadwal" dan jadwal langsung aktif tanpa perlu kuota Firestore!
